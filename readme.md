# Ask me anything!

## [Ask a question](../../issues/new) &nbsp;&nbsp;&nbsp; [Read questions](../../issues?q=is%3Aissue+is%3Aclosed+sort%3Aupdated-desc)

I’m [a coffee first developer](http://sapegin.me/), award-losing photographer, occasional leathercrafter, and dreamer of a boring life. Creator of [React Styleguidist](https://react-styleguidist.js.org), author of [Washing your code](https://sapegin.me/book/), learning to cook at [Tacohuaco](https://tacohuaco.co).

Occasionally, I get some questions – this way anyone can read the answer.

Frontend, open source, tools, blogging, photography, favorite food, dogs vs. cats, etc.

### Guidelines

- Check that your question hasn’t already been answered.
- Use a succinct title and description.
- Bugs and feature requests should be opened on the relevant issue tracker.
- Support questions are better asked on Stack Overflow.
- Be civil and polite.
- Don’t be afraid to answer someone else’s questions or add more to my answers.
- Try to use English.
